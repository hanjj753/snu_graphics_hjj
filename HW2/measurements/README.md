# HW2 Cornell Box Measurements

이 디렉터리는 실제 Cornell box를 렌더링 장면으로 재구성하기 위한 측정값을 보관한다.
별도 표기가 없으면 모든 길이 단위는 mm이다.

## 좌표계

- 원점: 내부 바닥면의 왼쪽 앞 모서리
- `+X`: 오른쪽
- `+Y`: 위쪽
- `+Z`: 앞쪽 개구면에서 뒷벽 방향
- 바닥 좌표 `(x, z)`는 3차원 좌표 `(x, 0, z)`를 뜻한다.
- 권장 렌더링 축척: `100 mm = 1 scene unit`

## Cornell box

| 항목 | 측정값 |
| --- | ---: |
| 내부 너비 | 290 mm |
| 내부 높이 | 300 mm |
| 내부 깊이 | 300 mm |
| 포맥스 두께 | 5 mm |
| 외부 너비 | 300 mm |
| 외부 높이 | 310 mm |

내부 범위:

```text
0 <= X <= 290
0 <= Y <= 300
0 <= Z <= 300
```

- 바닥, 천장, 뒷벽: 흰색
- 왼쪽 벽: 빨간색
- 오른쪽 벽: 초록색

## 카메라와 기준 사진

렌즈 중심은 상자 너비와 높이의 중앙에 있고 뒷벽 중앙을 바라본다.

```text
Camera position: (145, 150, -500) mm
Look-at target:  (145, 150,  300) mm
Up direction:    (  0,   1,    0)
```

| 사진 정보 | 값 |
| --- | --- |
| 카메라 | Samsung Galaxy Tab S9 후면 카메라 |
| 해상도 | 4128 x 3096 pixels |
| 종횡비 | 4:3 |
| 해상도 표기 | 13 MP |
| ISO | 1600 |
| 갤러리에 표시된 초점거리 | 23 mm |
| 노출 보정 | 0.0 EV |
| 조리개 | f/2.0 |
| 노출 시간 | 1/24 s |

23 mm를 35 mm 환산 초점거리로 간주한 초기 투영값:

```text
Horizontal FOV: 약 76.1 degrees
Vertical FOV (4:3): 약 60.8 degrees
```

렌더링은 수직 FOV 60.8도에서 시작하고, 자르지 않은 원본 사진의 상자 모서리와
비교한 뒤 필요할 때만 미세 조정한다.

권장 축척을 적용한 카메라 좌표:

```text
Camera position: (1.45, 1.50, -5.00)
Look-at target:  (1.45, 1.50,  3.00)
```

## 천장 조명

천장 정중앙의 60 mm x 60 mm 정사각형 구멍이다.

```text
Centre:  (145, 300, 150) mm
X range: 115 to 175 mm
Z range: 120 to 180 mm
```

실물 광원은 최대 밝기의 흰색 휴대전화 화면이다. 면광원을 지원하면 60 mm 정사각형
면광원을 사용하고, 기하 확인 단계에서는 중앙의 점광원으로 근사할 수 있다.

## 초코파이 상자

HW2에서는 텍스처가 없는 직육면체로 표현한다.

```text
바닥 단면: 60 x 210 mm
높이: 250 mm
회전 기준 꼭짓점: 바닥 (X, Z) = (210, 50)
```

위에서 보았을 때 회전 기준점에서 나가는 60 mm 변은 `+X`축으로부터 반시계 방향
30도이고, 210 mm 변은 이에 수직인 120도 방향이다.

```text
u = 60  * (cos(30 deg),  sin(30 deg))
v = 210 * (cos(120 deg), sin(120 deg))
```

| 꼭짓점 | X (mm) | Z (mm) |
| --- | ---: | ---: |
| P0, 회전 기준점 | 210.000 | 50.000 |
| P1 = P0 + u | 261.962 | 80.000 |
| P2 = P0 + v | 105.000 | 231.865 |
| P3 = P0 + u + v | 156.962 | 261.865 |

바닥 단면 중심:

```text
(183.481, 155.933) mm
```

높이 범위는 `0 <= Y <= 250 mm`이다.

## 컵과 물

```text
바닥 중심: (80, 180) mm
윗지름: 70 mm
아랫지름: 60 mm
컵 높이: 65 mm
물 높이: 35 mm
```

컵은 수직 원뿔대로 모델링한다. 컵 벽과 바닥 두께는 측정하지 않았다. HW2에서는
단일 표면으로 단순화해도 되며, 이후 과제를 위해 물은 별도 오브젝트로 유지한다.

## Blender/OBJ 기록 규칙

- 모든 Blender 오브젝트에 같은 좌표계와 축척을 사용한다.
- OBJ로 내보내기 전에 Object transforms를 적용한다.
- Blender에서 측정 위치까지 배치한 뒤 장면 전체를 하나의 OBJ로 내보낸다.
- OBJ 카메라는 현재 Python 뷰어가 사용하지 않으므로 측정 카메라는 Python에서 설정한다.
- HW2에서는 텍스처를 사용하지 않는다.
